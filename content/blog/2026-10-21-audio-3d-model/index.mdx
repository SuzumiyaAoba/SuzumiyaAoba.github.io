## 3D モデルの作成が簡単になった

Claude Code や Codex を始めとする Coding Agent (Harness) と最新モデル（Claude Opus 5.5、GPT-6.1 Sol）を使うことで、画像からある程度の品質を確保した 3D モデルを作成するのが簡単になった。それ以前のモデルでは、3D モデルを作成することはできたものの、形状が全く異なってしまっていたり、細かく指示しないと細部が作られないといった問題があった。プロンプトやスキルの工夫であるコントロールする余地はあったのだとは思うが、指示を書けるだけの知識が必要だっただろう。

しかし、Claude Opus 5.5 や GPT-6.1 Sol のようなモデルでは、複数の画像による空間把握、再現能力が大幅に向上し、細かい指示なしに画像から 3D モデルが作れるようになっている。

実際に私が持っているオーディオ機器を [オーディオページ](/audio/) で 3D 化している。

<AudioSystem />

意匠の問題があると思うので現実にあるものを 3D 化して販売する、という行為には注意した方がいいと思うが、手元にあるものを 3D 化して管理したり、Web サイト上で紹介することのハードルは著しく下がっている。

上記のオーディオシステムの 3D モデルも商品名を指定して、一つずつモデルを作成した後にそれらを使って接続方法を指定しただけで作れた。例えば、HD800S の 3D モデルが欲しかったら、以下のような指示を与えるだけでいい。

> HD 800 S の 3D モデルを HTML で閲覧できるように実装してください

Blender を使いたいのであれば「HTML で」のところを Blender を使って、と言えば恐らく実現してくれるだろう。まだ、細部の作りが甘いところがあるがブログでオーディオ環境を紹介するには十分ではないだろうか？

3D 化することに意味があるのかと言われれば完全に自己満足ではあるが、私のようなオーディオ初心者にとって他の人の構成を知るときにわかりやすくはあるだろう。価格コムのレビューやブログで構成を書いてくれている人がいるが、初心者は文字で見てもそれぞれの機器をどう繋いでいるのかわからない。

また、自分が何を買ったのか覚えておく意味でもいい気がしている。テキストでブログに残しておくだけでも十分ではあるが、視覚的に手元にあるものとの一致があるとわかりやすい。

今回はオーディオ環境を 3D モデル化したが、一つずつ作っていけば自身の部屋を再現することも可能だろう。

## オーディオ機器紹介

ここからは余談。実際に使っている機器の紹介。

### HD 800 S

<AmazonProductSection ids={["hd800s"]} />

HD 800 S はみんなおすすめしているヘッドホンなので改めて何か言うこともない気がする。この価格帯のヘッドホンは HD 800 S と Clear MG Pro の二つしか持っていないので中立な意見も書けない。ただ、音場の広さは多くの人が触れているようにこのヘッドホンの特徴だと思う。

低音が好きな人は合わないと思う。Clear MG Pro と比べるとほとんど無いと言っていいのではないかというくらい出ない。

### Clear MG Professional

<AmazonProductSection ids={["clear-mg-pro"]} />

20万円前後のヘッドホン買いたいなーと思ったとき、HD 800 S と合わせて検討していたヘッドホン。先にこちらを買って、その後に結局 HD 800 S を買った。

HD 800 S との比較だと全てが歪んでしまう気がするが、自分の中ではこれを開放型ヘッドホンの標準としている。比較ではないので感覚に基づく感想でしかないが、開放型にしては低音が出ているヘッドホンなのではないかと思う。HD 800 S の低音が出てなさすぎて感覚が狂ってるだけかもしれない。

### UD-505、CG-10M

UD-505 はヘッドホンアンプ、CG-10M はマスタークロックジェネレータ。UD-505 はもう生産されていないので後継の UD-505-X、もしくはそれも生産終了して在庫分しかないので [UD-507](https://teac.jp/jp/product/ud-507/top) が対応する製品になる？

<AmazonProductSection ids={["ud-505-x"]} />

最初に UD-505 を買って、その後に Clear MG Professional、そして CG-10M という順番で買った記憶がある。マスタークロックジェネレータの効果をちゃんと感じられているかはわからない。ずっと繋いで聴いてるから時より外して聴くのがいいのかも。

### HA-1A MK2

恐らく年始のタイミングで [SUPER KOPEK](https://superkopek.jp/collections/cayin) のセールで安くなっていたタイミングで買った。HD 800 S の次に買ってよかったと思った。真空管アンプの中では安い方だと思うが、アナログアンプ通すと音が変わるし、聴いていて楽しくなるのを実感できた。

UD-505 と HA-1A MK2 を組み合わせたレビューが価格コムでいくつかされているが感想としては同じ。UD-505 単体だと聴いていて楽しさがないと言うのか、悪くないけど…と感じてしまう。そのあたりがこのアンプを通すことで改善した。

DAC/ヘッドホンアンプもアナログアンプも一つしか持っていないのでレビューというレビューが書けない。

## まとめ

途中からオーディオ危機の紹介になってしまったが、最初に戻ると 3D モデル作るの簡単になっている話。3D モデル生成サービスを使ってもいいけど、クオリティそこそこでいいなら Claude Code や Codex でも十分。Claude や ChatGPT を契約している人は試してみてね。
