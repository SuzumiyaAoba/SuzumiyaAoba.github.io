## ひとことで

いったん描き終えた画面を画像として保持し、その画像を**少しずらした位置から読み直して**描くことで、熱気の揺らぎ（陽炎）、ガラスや水の屈折、衝撃波の歪みを表現する手法です。本当に光の屈折を計算するわけではありませんが、画面を 1 回読むだけの安いコストで、見た目にはかなり説得力のある「空気の揺らぎ」が得られます。

## ゲームでの使いどころ

- **陽炎・熱気**：焚き火、ジェットエンジンの排気、砂漠の地平線、溶岩の上の空気。
- **衝撃波**：爆発やスキルの発動で、空間が輪状に押し広げられる歪み。
- **屈折**：水面越しの景色、ガラスの球や瓶、透明なバリア、透明化したキャラクターの輪郭。
- **画面演出**：ダメージを受けたときの揺らぎ、ワープ、夢や回想の場面転換。

## しくみ

1. シーン（歪ませたいものを除く）を**レンダーテクスチャ**に描く。
2. 画面全体（または歪みを起こす板やメッシュ）を描くとき、各画素で「どれだけずらして読むか」のオフセット $\Delta$ を計算する。
3. $c = T_{\text{scene}}(\mathbf{uv} + \Delta)$ として描く。

オフセットの作り方で表現が変わります。

| 表現             | オフセットの作り方                                    |
| ---------------- | ----------------------------------------------------- |
| 陽炎             | 上へ流れるノイズ × 範囲のマスク（炎の上の縦長の領域） |
| 衝撃波           | 中心からの距離が輪の半径に近い画素を、放射方向へ押す  |
| ガラス・水の屈折 | 表面の法線（や法線マップ）の画面上の成分 × 強さ       |

実際のゲームでは、オフセットを描いた専用のバッファ（歪みバッファ）を用意し、パーティクルやメッシュが「ここをこれだけ歪ませたい」という値を書き込んで、最後に 1 回の全画面パスでまとめて適用する構成がよく使われます。

## 実装のポイント

```glsl
uniform sampler2D uScene;     // いったん描いた画面
vec2 offset = vec2(0.0);
// 陽炎：炎の上で、上へ流れるノイズ
float mask = smoothstep(1.0, 0.2, length((vUv - uFire) / uFireSize));
offset += vec2(snoise(vec3(vUv * 14.0 - vec2(0.0, uTime * 3.0), uTime)),
               snoise(vec3(vUv * 14.0, uTime) + 17.0)) * 0.006 * mask;
// 衝撃波：輪の近くだけ外へ押す
float ring = 1.0 - smoothstep(0.0, 0.05, abs(length(vUv - uCenter) - uRadius));
offset -= normalize(vUv - uCenter) * ring * 0.04;
gl_FragColor = texture2D(uScene, vUv + offset);
```

- **手前の物体を歪ませない**：歪みを起こす物体より手前にある物体まで歪むと不自然です。深度を比較して、歪み源より手前の画素は元の位置から読むようにします。
- **画面外参照**：画面の端でオフセットすると、画面外（何も描かれていない領域）を読んでしまいます。端に近いほどオフセットを弱めます。
- **HDR のまま扱う**：トーンマッピング前の明るさでずらし、最後にトーンマッピングすると、明るい光源が歪んでもにじみが自然です。

## つまずきやすい点

- **画面に無いものは写らない**：屈折の向こう側に見えるべき物体が画面外や遮蔽されていると、映り込みません。これは[画面空間反射](/keywords/graphics/post/screen-space-reflections/)と同じ、画面空間の手法共通の限界です。
- **透明物との順序**：歪みのパスより後に描いた半透明物は歪まず、前に描いたものは歪みます。どの段階で歪ませるかを決めておく必要があります。
- **強すぎる歪み**：オフセットが大きすぎると、画像がちぎれたように見えます。数ピクセル程度が自然な上限です。

## デモで試すこと

1. 焚き火の上の壁の目地が揺らいで見えるのが陽炎です。「陽炎」をオフにすると揺らぎが消えます。
2. 「衝撃波」を押すと、床の一点から輪が広がり、背景の壁が押し広げられるように歪みます。
3. 「ずらし量を色で表示」をオンにすると、画面のどこをどれだけずらしているかが色で見えます。
