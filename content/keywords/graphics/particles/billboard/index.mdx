## ひとことで

四角い板（2 枚の三角形）に画像を貼り、その板の正面を**毎フレームカメラの方へ向け直す**描画方法です。煙・炎・光・木の葉の遠景など、本物の立体で作ると重すぎるものを、ほとんどコストをかけずに「どの角度から見ても厚みのある物体」に見せられます。パーティクル描画の最も基本的な形です。

## ゲームでの使いどころ

- **煙・炎・爆発・魔法の光**：ほぼすべてのパーティクルエフェクトの粒は、ビルボードです。
- **遠景の木や草**：遠くの木を 1 枚の板（インポスター）に置き換えて描画負荷を下げる。
- **UI 的な表示**：敵の頭上の HP バー、名前、ダメージ数値、クエストマーカー。
- **レンズフレア・光のにじみ**：光源の位置に置く光の板。

## しくみ

ビルボードの頂点は、ワールド座標ではなく**カメラ空間（ビュー空間）で広げる**のが最も簡単です。

1. 粒子の中心 $\mathbf{c}$ をビュー空間に変換する：$\mathbf{c}_v = V\,\mathbf{c}$
2. 板の角のオフセット $(\pm\tfrac12, \pm\tfrac12)$ に大きさ $s$ を掛け、ビュー空間の $x, y$ に足す
3. 射影行列を掛けて画面に出す

$$
\mathbf{p}_{\text{clip}} = P\left(V\,\mathbf{c} + s\,(u, v, 0)\right)
$$

ビュー空間の $x, y$ 軸は常に画面の横と縦なので、板は必ずカメラに正対します。回転させたい場合は $(u, v)$ を 2D で回転してから足します（煙の渦の表現によく使います）。

用途に応じて、向け方にはいくつかの種類があります。

| 種類 | 向け方 | 用途 |
| --- | --- | --- |
| スクリーン整列 | 画面と平行（上の方法） | 煙、光、火の粉 |
| 軸固定（円柱） | 縦軸は固定し、水平方向だけカメラへ | 木、草、たいまつの炎 |
| 速度方向 | 画面上の速度の向きへ伸ばす | 雨、火花（[ストレッチビルボード](/keywords/graphics/particles/stretched-billboard/)） |

## 実装のポイント

```glsl
// 頂点シェーダー：インスタンスごとの中心・大きさ・回転を受け取る
attribute vec3 iPosition;
attribute float iSize;
attribute float iRotation;
void main() {
  vec2 corner = position.xy;                       // -0.5〜0.5 の四角形
  float c = cos(iRotation), s = sin(iRotation);
  corner = vec2(c * corner.x - s * corner.y, s * corner.x + c * corner.y);
  vec4 mv = modelViewMatrix * vec4(iPosition, 1.0);
  mv.xy += corner * iSize;                         // ビュー空間で広げる
  gl_Position = projectionMatrix * mv;
}
```

- **インスタンシングでまとめて描く**：板 1 枚ずつ描画命令を出すと重いので、数千枚を 1 回の描画で済ませます。
- **半透明の合成**：光や炎は加算合成（明るさを足す）、煙は通常のアルファ合成が基本です。アルファ合成では奥から手前へ描く並べ替えが必要になります。境界のにじみを防ぐには[乗算済みアルファ](/keywords/graphics/volume/premultiplied-alpha/)を使います。
- **地面への刺さり**：大きな煙の板が地面や壁と交わると硬い線が見えます。[ソフトパーティクル](/keywords/graphics/particles/soft-particles/)で和らげます。

## つまずきやすい点

- **板の薄さがばれる**：カメラ正対でない（ワールドに固定した）板は、横から見ると紙のように薄く見えます。デモの「ワールドに固定」で確認できます。
- **真上から見たとき**：軸固定のビルボードは、真上から見ると線になってしまいます。見下ろし視点のゲームでは向け方を工夫します。
- **オーバードロー**：大きな半透明の板が何枚も重なると、同じ画素を何十回も塗ることになり GPU が重くなります（[オーバードロー](/keywords/implementation/performance/overdraw/)）。枚数より 1 枚の大きさが効きます。

## デモで試すこと

1. 視点が自動で回っていても、煙は常に厚みのある柱に見えます。これは 70 枚の板が毎フレームカメラへ向き直っているからです。
2. 「板の輪郭を表示」をオンにすると、煙が四角い板の集まりであることが分かります。
3. 「ワールドに固定」に切り替え、視点が横へ回ったときの見え方の違いを比べてください。
