## ひとことで

一定の周期で**端と端がぴったりつながる**ように作ったノイズです。テクスチャとして並べても継ぎ目が見えず、スクロールしてもループしても破綻しません。ゲームの素材の多くはタイリング（繰り返し貼り付け）が前提なので、手続き的にテクスチャを作るときの必須テクニックです。

## ゲームでの使いどころ

- **タイリングテクスチャの生成**：地面、岩、雲、水面のノーマルマップなど、繰り返し貼る素材をノイズから焼き出すとき。
- **UV スクロールする素材**：炎や水の模様を[UV スクロール](/keywords/graphics/materials/uv-scrolling/)で流し続けても、1 周したところで途切れません。
- **ループするアニメーション**：時間方向を周期にすると、何秒かでぴったり元に戻るエフェクト素材（ループ GIF、フリップブック）を作れます。
- **円柱・トーラス状のワールド**：横方向がつながったマップ（例：惑星を一周できるストラテジー）の地形生成。

## しくみ

格子ベースのノイズ（パーリンなど）では、格子点ごとに勾配ベクトルや乱数を決めています。周期 $P$ のノイズを作るには、**格子座標を周期で折り返してからハッシュする**だけです。

$$
\mathbf{g}(i, j) = \text{gradient}\big(\text{hash}(i \bmod P,\; j \bmod P)\big)
$$

こうすると $x = 0$ の格子点と $x = P$ の格子点が同じ勾配を持つため、両端の値も傾きも一致します。fBm として重ねる場合は、各オクターブの周期も周波数と同じ倍率で増やします（周波数 2 倍なら周期も 2 倍）。周期が整数でないと格子点が一致しないので、**周期は整数**にします。

もう 1 つの方法は、**高次元の円周上を回る**やり方です。2D のタイルを作るとき、$x$ を円 $(\cos 2\pi u,\, \sin 2\pi u)$、$y$ も別の円に写し、4D ノイズで評価します。周期の自由度が高く、任意の格子を持たない関数（simplex 等）にも使えますが、次元が倍になるぶん計算は重くなります。

## 実装のポイント

```glsl
float perlinPeriodic(vec2 p, vec2 period) {
  vec2 i = floor(p), f = p - i;
  vec2 i00 = mod(i, period);
  vec2 i10 = mod(i + vec2(1.0, 0.0), period);
  vec2 i01 = mod(i + vec2(0.0, 1.0), period);
  vec2 i11 = mod(i + vec2(1.0, 1.0), period);
  // 以降は通常のパーリンノイズと同じ（勾配 × 距離の内積を補間）
  ...
}

// タイル 1 枚ぶんの UV (0〜1) を周期 4 の格子にのせる
float n = perlinPeriodic(uv * 4.0, vec2(4.0));
```

- **ずらし（オフセット）も周期で**：層ごとにオフセットを加える場合、オフセットを整数にしないと周期性が崩れます。
- **ブラーや後処理もラップして**：生成後にぼかしや法線計算をするときは、端の画素が反対側の端を参照するようにします。

## つまずきやすい点

- **周期が見えてしまう**：継ぎ目は消えても、同じ模様が規則的に並ぶこと自体は隠せません。遠景で目立つなら、[テクスチャボミング](/keywords/graphics/materials/texture-bombing/)や[ワン・タイル](/keywords/world/generation/wang-tiles/)、別スケールのノイズの重ね合わせで反復感を崩します。
- **普通のノイズの切り出しで済ませる**：画像の端をクロスフェードして無理につなぐ方法もありますが、コントラストが落ちてぼやけた帯ができます。
- **周期が小さすぎる**：周期 2 などでは、格子の勾配の組み合わせが少なく、模様が単調になります。

## デモで試すこと

1. 「タイルの作り方」を**通常のノイズを切り出す**に切り替え、「タイルの境目を表示」をオフにしてください。境目に沿って段差が走るのが見えます。
2. **周期ノイズ**に戻すと、同じ模様を 9 枚並べているのに、つなぎ目がどこにあるか分からなくなります。
3. 「模様をスクロール」をオンにすると、タイル内の模様が流れ続けても端で途切れないことを確認できます。
