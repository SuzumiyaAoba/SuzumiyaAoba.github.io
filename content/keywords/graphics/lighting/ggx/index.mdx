## ひとことで

表面を顕微鏡で見ると、目に見えないほど小さな平らな面（**微小面**）が、いろいろな向きに傾いて並んでいると考えられます。**GGX**（Trowbridge–Reitz 分布）は、その微小面の法線が「どの向きにどれくらいの割合で向いているか」を表す**法線分布関数**です。粗さのパラメーター 1 つで、鏡のような表面からざらざらの表面まで表せ、しかも中心が鋭く周りに長い裾を持つので、現実の素材のハイライトによく合います。現代のゲームエンジンの標準的な鏡面反射モデルです。

## ゲームでの使いどころ

- **PBR マテリアルの鏡面反射**：Unreal Engine、Unity、Frostbite、three.js などの標準マテリアルの $D$ 項。
- **ハイライトの見た目**：濡れた路面、車の塗装、磨かれた金属、プラスチック。GGX の長い裾が、光源の周りのにじみ（グロー）を自然に作ります。
- **環境マップのぼかし**：[環境マップ照明](/keywords/graphics/lighting/image-based-lighting/)で、粗さごとにぼかした環境マップを事前計算するときにも、GGX 分布で方向を選びます（[重要度サンプリング](/keywords/world/sampling/importance-sampling/)）。

## しくみ

光の方向 $\mathbf{l}$ と視線 $\mathbf{v}$ の中間の向き（ハーフベクトル）$\mathbf{h} = \text{normalize}(\mathbf{l} + \mathbf{v})$ を向いた微小面だけが、光を視線の方向へ鏡のように反射します。そのような微小面がどれだけあるかを表すのが $D(\mathbf{h})$ です。

$$
D_{\text{GGX}}(\mathbf{h}) = \frac{\alpha^2}{\pi\,\big((\mathbf{n}\cdot\mathbf{h})^2(\alpha^2 - 1) + 1\big)^2},
\qquad \alpha = \text{roughness}^2
$$

- $\alpha$ が小さい（滑らか）と、ほとんどの微小面が表面の法線と同じ向きを向き、反射は鏡の方向に鋭く集まります。
- $\alpha$ が大きい（粗い）と、微小面の向きがばらつき、反射が広い範囲に広がります。
- 粗さを 2 乗して $\alpha$ にするのは、アーティストが操作するスライダーの変化が見た目の変化と比例するようにするため（Disney の提案）です。

**他の分布との違い**

| 分布        | 特徴                                                     |
| ----------- | -------------------------------------------------------- |
| Blinn-Phong | 古くからの近似。ハイライトの裾が短く、プラスチックっぽい |
| Beckmann    | 物理的な根拠がある分布。裾は GGX より短い                |
| GGX         | 中心が鋭く、裾が長い。実測した素材によく合う             |

$D$ だけでは反射モデルにならず、実際には幾何減衰 $G$（微小面同士の影）と[フレネル](/keywords/graphics/lighting/fresnel/) $F$ を組み合わせて使います（[PBR・BRDF](/keywords/graphics/lighting/physically-based-rendering/)）。

## 実装のポイント

```glsl
float D_GGX(float NoH, float roughness) {
  float a = roughness * roughness;
  float a2 = a * a;
  float d = NoH * NoH * (a2 - 1.0) + 1.0;
  return a2 / (PI * d * d);
}
// GGX 分布に従う微小面の法線を選ぶ（重要度サンプリング）
float theta = atan(a * sqrt(u1 / (1.0 - u1)));
float phi = 2.0 * PI * u2;
```

- **粗さの下限**：$\alpha$ が 0 に近いと分母が 0 に近づき、ハイライトが 1 画素の点になってちらつきます。0.02〜0.05 程度の下限を設けるのが一般的です。
- **幾何減衰との組み合わせ**：GGX には、同じ分布から導かれる Smith の幾何減衰（高さ相関版）を組み合わせるのが正確です。
- **異方性への拡張**：$\alpha$ を方向ごとに $\alpha_x, \alpha_y$ と分けると、[異方性反射](/keywords/graphics/lighting/anisotropic-reflection/)になります。

## つまずきやすい点

- **粗さの定義の違い**：エンジンやツールによって、「粗さ」をそのまま $\alpha$ にするか、2 乗するかが違うことがあります。ツール間で素材を移すと見た目が変わる原因になります。
- **小さなハイライトのエイリアシング**：粗さの低い面に細かい法線マップを組み合わせると、ハイライトがちらつきます（鏡面エイリアシング）。法線のばらつきに応じて粗さを上げる対策（Toksvig など）があります。
- **エネルギーの損失**：粗い表面では、微小面間の多重反射が無視されるため、少し暗くなります。高品質なレンダラーでは補正項を足します。

## デモで試すこと

1. 左の「微小面の集まり」で粗さを上げると、小さな鏡の向きがばらばらになり、反射した光の向き（水色の線）が広い範囲に散らばります。
2. 右下のグラフは、法線からずれた角度ごとの分布の値（対数目盛）です。GGX は Beckmann や Blinn-Phong よりも、角度が大きいところで値がゆっくり下がる「長い裾」を持っています。
3. 右の球で分布関数を切り替えると、GGX ではハイライトの周りにうっすらとにじみが広がり、他の分布ではハイライトの縁がくっきり切れるのが分かります。
