## ひとことで

素材の上に**透明で滑らかな塗膜の層をもう 1 枚重ねて**、2 層分の反射を足し合わせる表現です。車の塗装、ニスを塗った木、コーティングされた床、濡れた石、プラスチックのおもちゃ、革靴などは、下地の質感（色・粗さ・メタリックの粒子）の上に、鏡のようにくっきりした映り込みが重なっています。1 層の PBR では「粗い」か「滑らか」のどちらかしか表せませんが、クリアコートなら両方を同時に表せます。

## ゲームでの使いどころ

- **レースゲームの車の塗装**：クリアコート表現の代名詞です。メタリックの下地と、深い艶のある塗膜の映り込み。
- **家具・楽器**：ニス塗りの木製家具、ピアノ、ギター。
- **雨に濡れた路面や物体**：乾いた素材の上に、水の膜の反射を重ねる。
- **プラスチック・陶器・漆器**：表面に艶のある工業製品や工芸品。

## しくみ

光は次のように 2 回反射します。

1. **塗膜の表面での反射**：透明な塗膜（屈折率 1.5 程度、$F_0 \approx 0.04$）で、[フレネル](/keywords/graphics/lighting/fresnel/)に応じた割合の光が鏡のように反射します。塗膜は滑らかなので、くっきりしたハイライトと映り込みになります。
2. **下地での反射**：塗膜を通り抜けた光が、下地の素材（色の付いたメタリック塗装など）で反射します。

$$
L = F_c \cdot L_{\text{塗膜}} + (1 - F_c)\cdot L_{\text{下地}}
$$

塗膜で反射した分（$F_c$）だけ、下地に届く光は減ります（エネルギー保存）。浅い角度ではフレネル効果で $F_c$ が大きくなるので、車体の側面を低い角度から見ると、塗膜の映り込みが強くなります。

**メタリック塗装**：下地には、アルミの小さな薄片（フレーク）が混ぜられていて、ランダムな向きの小さな鏡としてきらめきます。デモでは、ランダムな向きの法線マップでこの粒子を表現しています。

**ゆず肌**：実際の塗装面には、ゆずの皮のようなゆるやかなうねりがあります。塗膜の層にだけ弱い法線マップを使うと、映り込みがわずかに揺らいで、よりリアルになります。

## 実装のポイント

```js
// three.js：MeshPhysicalMaterial のクリアコート
const paint = new THREE.MeshPhysicalMaterial({
  color: "#b3131b",
  metalness: 0.55,
  roughness: 0.45, // 下地（メタリック塗装）は粗め
  normalMap: flakeNormals, // 粒子のきらめき（下地だけに効く）
  clearcoat: 1, // 塗膜の強さ
  clearcoatRoughness: 0.04, // 塗膜は滑らか
  clearcoatNormalMap: orangePeel, // 塗膜のうねり
});
```

- **法線を層ごとに分ける**：下地の法線マップ（粒子、傷）と、塗膜の法線（滑らか、またはゆず肌）を別々にできるのがクリアコートの利点です。
- **コスト**：鏡面反射の計算が 2 回分になるので、通常のマテリアルより少し重くなります。車のボディなど、必要な部分だけに使います。
- **環境マップが重要**：塗膜の映り込みは景色そのものなので、良い[環境マップ](/keywords/graphics/lighting/image-based-lighting/)がないと効果が出ません。

## つまずきやすい点

- **クリアコートを粗くしすぎる**：塗膜の粗さを上げると、下地とほとんど区別がつかなくなり、2 層にする意味が薄れます。
- **塗膜の色**：現実の透明な塗膜は色をほとんど持ちません。色の付いた塗膜（キャンディ塗装など）を表すには、下地に届く光を色で吸収させる設定が別に必要です。
- **傷や汚れ**：現実の車は、塗膜にだけ細かい傷（渦巻き状の洗車傷など）があります。塗膜の粗さマップに傷を描くとリアルになります。

## デモで試すこと

1. 手前の 3 つの球を比べてください。「塗装のみ」はぼんやりした広いハイライトだけ、「クリアコート」はその上にくっきりした光の点と映り込みが重なっています。
2. 「クリアコートの強さ」を 0 にすると、車の艶が消え、つや消しの塗装になります。
3. 「塗膜の粗さ」を上げると、くっきりしたハイライトがにじんで、2 層の違いが分からなくなります。
4. 「メタリックの粒子」をオフにすると、きらめきが消えてソリッドカラーの塗装になります。
