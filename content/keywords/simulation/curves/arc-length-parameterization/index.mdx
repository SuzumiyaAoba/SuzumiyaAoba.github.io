## ひとことで

曲線のパラメータ $t$ と「曲線に沿って進んだ距離（弧長）$s$」の対応表を作り、**距離から $t$ を逆引き**する手法です。ほとんどの曲線は $t$ を一定に増やしても一定の速さでは進まないため、「一定速度で動かす」「等間隔に物を並べる」ときに欠かせません。

## ゲームでの使いどころ

- **一定速度の移動**：レール上のカメラ、乗り物、弾、パトロールする敵。速度むらはプレイヤーにすぐ気づかれます。
- **等間隔の配置**：道路の白線、柵の杭、街灯、ロープの結び目などを曲線に沿って等間隔に置く。
- **進捗の表示**：「コース全体の何 % まで来たか」を距離で計算するレースの順位判定やミニマップ。
- **テクスチャの貼り付け**：曲線に沿ったリボンや道路メッシュに、伸び縮みのない UV を与える。

## しくみ

弧長は、速度ベクトルの大きさを積分したものです。

$$
s(t) = \int_0^t \left\lVert \frac{d\mathbf{P}}{d\tau} \right\rVert d\tau
$$

ほとんどの曲線でこの積分は解析的に解けないため、実用では**数値的な表**を作ります。

1. $t$ を $N$ 等分し、各点 $\mathbf{P}(t_k)$ を求める。
2. 隣り合う点の距離を累積して $s_k$ の表を作る（折れ線近似）。
3. 距離 $s$ が与えられたら、表を**二分探索**して $s_k \le s < s_{k+1}$ となる $k$ を見つけ、区間内を線形補間して $t$ を得る。

デモ右下のグラフは $s(t)$（全長で正規化）です。等速なら点線の直線になるはずが、実際には曲がっています。傾きが緩い区間は $t$ が進んでも距離が伸びない、つまり**遅い**区間です。

## 実装のポイント

```ts
function buildArcLengthTable(curve: Curve, samples = 200) {
  const lengths = [0];
  let prev = curve.getPoint(0);
  for (let i = 1; i <= samples; i++) {
    const p = curve.getPoint(i / samples);
    lengths.push(lengths[i - 1] + p.distanceTo(prev));
    prev = p;
  }
  return lengths;
}

function tAtDistance(lengths: number[], s: number) {
  let lo = 0,
    hi = lengths.length - 1;
  while (lo < hi - 1) {
    const mid = (lo + hi) >> 1;
    if (lengths[mid] < s) lo = mid;
    else hi = mid;
  }
  const f = (s - lengths[lo]) / (lengths[hi] - lengths[lo]);
  return (lo + f) / (lengths.length - 1);
}
```

- **表は形が変わったときだけ作り直す**：毎フレーム作る必要はありません。制御点を編集したときに再計算します。
- **three.js**：`Curve.getPointAt(u)` と `getSpacedPoints(n)` はこの表（`getLengths`）を内部で使っています。
- **精度の目安**：分割数はカーブの急さ次第ですが、ゲームでは 100〜200 程度で十分なことがほとんどです。ニュートン法で $t$ を補正するとさらに精度を上げられます。

## つまずきやすい点

- **分割数が少ないと速度むらが残る**：表の区間内は直線とみなしているので、急カーブでは誤差が出ます。デモで分割数を 3〜5 にすると、水色の車もぎくしゃくします。
- **閉じた曲線の継ぎ目**：ループするコースでは、$s = L$（全長）と $s = 0$ が同じ点になるよう、剰余の扱いに注意します。
- **速度が可変の場合**：加減速したいなら、距離 $s$ 自体を時間の関数（イージングや物理）で動かし、その $s$ から $t$ を引きます。「速さの設計」と「形の設計」を分離できるのがこの手法の利点です。

## デモで試すこと

1. 赤い車（$t$ を一定に増やす）は、通過点が詰まった左上のカーブで遅くなり、間隔の広い長い直線で急加速します。水色の車（弧長）は常に同じ速さです。
2. 「等間隔の目盛り」の赤い点は $t$ を等間隔にした位置、水色は距離を等間隔にした位置です。赤は偏り、水色は均等に並びます。
3. 「弧長テーブルの分割数」を 3 にすると、表が粗すぎて水色の車にも速度むらが出ます。
