## メモ

_Plain Old **Common Language Runtime** Object_ の略。特定のフレームワークの基底クラスやインターフェイスに依存しない、通常の CLR クラスを指す。Java の POJO に対応する考え方で、Entity Framework では永続化の仕組みをクラスに持ち込まないエンティティを表す場合にも使う。
